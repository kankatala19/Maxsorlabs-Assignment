# Returns

Customers may request a return within 30 days of delivery.

Eligible returns:
- Unused items in original packaging
- Wrong size or wrong item shipped
- Item does not match the product listing

The customer must provide the order number and a short reason.

After a return is approved:
- Send a prepaid return label
- Refund or replacement is processed after the warehouse receives the item

Do not approve a return when:
- The item is used, washed, or missing parts
- The item is final sale, underwear, or opened software
- The request is more than 30 days after delivery

If photos are needed to confirm condition, request photos.
If the order number is missing, request more information.
